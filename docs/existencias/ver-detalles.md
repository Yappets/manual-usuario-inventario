# Ver Detalles

La funcionalidad **Ver Detalles** permite consultar información detallada sobre las existencias registradas en el sistema.

A través de esta pantalla, el usuario puede visualizar el estado actual de los productos  mediante distintos criterios de búsqueda y filtrado.

## Acceso a la pantalla

Para acceder a esta funcionalidad, el usuario debe ingresar a la sección **Existencias** y seleccionar la opción **Ver Detalles**, ubicada en la parte superior derecha de la pantalla.

![Acceso a pantalla de egreso](/img/ver-detalles/1.png)

Una vez seleccionada la opción, el sistema muestra la pantalla **Detalle de Existencias**, desde la cual es posible consultar productos registrados en los distintos estados contemplados por el sistema.

![Pantalla ver detalles](/img/ver-detalles/2.png)


## Estados de consulta

La búsqueda de información se encuentra organizada en tres pestañas, cada una correspondiente a un estado diferente de las unidades de productos.

* **En Depósito**
* **Pendiente de Egreso**
* **Egresado**


# En Depósito

La pestaña **En Depósito** permite consultar los productos que actualmente se encuentran disponibles dentro de los depósitos registrados en el sistema.

Al ingresar a esta pestaña, el sistema muestra por defecto todas las existencias disponibles en todos los depósitos.

![En deposito](/img/ver-detalles/3.png)

## Filtros disponibles

### Depósito

Permite limitar la consulta a un depósito específico.

Al seleccionar un depósito, el sistema mostrará únicamente las unidades de productos que se encuentren disponibles en dicho depósito.

### Producto

Permite buscar un producto específico mediante su código o descripción.

Al aplicar este filtro, el sistema mostrará únicamente las existencias correspondientes al producto seleccionado.

# Pendiente de Egreso

La pestaña **Pendiente de Egreso** permite consultar las unidades de productos que ya fueron seleccionadas para ser asignadas a una ubicación, pero cuyo egreso aún no fue confirmado.

Al ingresar a esta pestaña, el sistema muestra todas las unidades que se encuentran actualmente en estado **Pendiente de Egreso**, indicando además el depósito de origen de cada una de ellas.

![Pendiente de Egreso](/img/ver-detalles/4.png)


## Filtros disponibles

### Depósito

Permite visualizar únicamente las unidades pendientes de egreso que provienen de un depósito determinado.

### Producto

Permite consultar únicamente las unidades pendientes de egreso correspondientes a un producto específico.

---

# Egresado

La pestaña **Egresado** permite consultar las unidades de productos que ya fueron asignadas a una ubicación dentro de la organización.

Estas ubicaciones pueden corresponder a oficinas o fuentes de abastecimiento.

Al ingresar a esta pestaña, el sistema selecciona por defecto el tipo de ubicación **Oficina** y la opción **Todas las oficinas**, mostrando todas las unidades que se encuentran actualmente egresadas junto con la ubicación a la que fueron asignadas.


![Egresado](/img/ver-detalles/5.png)

## Filtros disponibles

### Tipo de ubicación

Permite filtrar los resultados según el destino asignado al producto.

Las opciones disponibles son:

* **Oficina**
* **Fuente de Abastecimiento**

#### Oficina

Al seleccionar esta opción, el sistema muestra el organigrama institucional para permitir la selección de una oficina específica.

Una vez seleccionada la oficina, se mostrarán únicamente las unidades asignadas a dicha dependencia.

#### Fuente de Abastecimiento

Al seleccionar esta opción, el sistema habilita el campo **Fuente**, desde el cual es posible buscar y seleccionar una fuente de abastecimiento determinada.

El resultado mostrará únicamente las unidades asignadas a la fuente seleccionada.

### Origen

Permite filtrar la información según el mecanismo mediante el cual las unidades fueron incorporadas al sistema.

Las opciones disponibles permiten identificar si la información proviene de:

* Productos registrados mediante los procesos habituales de gestión de inventario.
* Productos incorporados mediante relevamientos realizados dentro del sistema.

### Producto

Permite consultar únicamente las unidades egresadas correspondientes a un producto específico.

---

## Consideraciones

Se recomienda utilizar los filtros disponibles para reducir la cantidad de resultados y facilitar la localización de información específica.

La funcionalidad **Ver Detalles** constituye la principal herramienta de consulta del sistema, permitiendo obtener una visión completa del estado y ubicación de las existencias registradas.

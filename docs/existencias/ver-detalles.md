# Ver detalles de productos

La funcionalidad **Ver detalles** permite consultar información más específica sobre los productos registrados en el sistema.

Desde esta pantalla se pueden obtener reportes relacionados con productos disponibles, egresados o pendientes de egreso.

## Objetivo

El objetivo de esta funcionalidad es facilitar la búsqueda y consulta detallada de productos, permitiendo conocer su estado, ubicación y origen de carga.

## Filtros disponibles

La pantalla permite aplicar distintos filtros para mejorar la búsqueda de información.

Entre los filtros disponibles se encuentran:

| Filtro | Descripción |
|---|---|
| Localidad | Permite buscar productos según la localidad donde se encuentran. |
| Depósito | Permite filtrar productos según el depósito asociado. |
| Origen de carga | Permite distinguir si el producto fue ingresado desde el sistema América o relevado en el nuevo sistema. |

## Estados consultables

Desde esta sección se pueden consultar productos en distintos estados:

- Productos disponibles en depósito.
- Productos egresados.
- Productos pendientes de egreso.

## Resultado esperado

Al aplicar los filtros correspondientes, el sistema muestra los productos que cumplen con los criterios seleccionados, permitiendo obtener una vista más precisa del inventario.

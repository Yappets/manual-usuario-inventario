# Existencias

La pantalla de **Existencias** permite consultar los productos disponibles en los distintos depósitos registrados en el sistema.

La información se presenta en una tabla que muestra los datos principales de cada producto, junto con su cantidad totalizada y el depósito en el que se encuentra.

![Pantalla de Existencias](/img/existencias.png)

## Información disponible

La tabla de existencias muestra los siguientes datos:

| Campo | Descripción |
|---|---|
| Código | Código identificador del producto. |
| Descripción | Nombre o descripción detallada del producto. |
| Cantidad | Cantidad total disponible del producto. |
| Depósito | Nombre del depósito donde se encuentra el producto. |
| Cuenta | Número de cuenta contable asociada al producto. |

## Acciones disponibles

En la esquina superior derecha de la pantalla se encuentran los botones de acceso a las principales acciones relacionadas con las existencias:

- **Egresar**
- **Relevar**
- **Ver detalles**

Estas acciones permiten gestionar el movimiento, registro y consulta detallada de los productos dentro del sistema.

## Egresar productos

La opción **Egresar** permite asignar una o varias unidades de productos a una oficina del organigrama o a una fuente de abastecimiento.

Esta acción se utiliza para productos que ya fueron egresados previamente en el sistema América.

El objetivo es registrar con mayor precisión la ubicación actual de cada unidad de producto, permitiendo conocer si se encuentra asignada a una oficina, área o fuente específica.

## Relevar productos

La opción **Relevar** permite registrar una o varias unidades de productos que fueron egresadas antes de la puesta en marcha del nuevo sistema.

Estos productos no figuran actualmente como disponibles en depósito ni como egresados dentro del sistema, por lo que deben ser cargados manualmente mediante el relevamiento.

El objetivo de esta funcionalidad es incorporar al sistema unidades de productos existentes físicamente, pero que aún no se encuentran registradas.

## Ver detalles de productos

La opción **Ver detalles** permite consultar reportes más específicos sobre los productos registrados en el sistema.

Desde esta funcionalidad se pueden visualizar productos disponibles en depósitos, productos egresados y productos pendientes de egreso.

Además, permite aplicar filtros para facilitar la búsqueda de información, por ejemplo:

- Localidad donde se encuentra el producto.
- Nombre del depósito.
- Origen de carga del producto, ya sea desde el sistema América o mediante relevamiento en el nuevo sistema.

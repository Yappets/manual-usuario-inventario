# Inicio

La pantalla de **Inicio** presenta un resumen general de la información almacenada y gestionada por el sistema.

Desde esta sección, el usuario puede visualizar rápidamente los principales indicadores del sistema, entre ellos:

- Cantidad de usuarios registrados.
- Cantidad total de productos.
- Cantidad de depósitos.
- Cantidad total de existencias.
- Cantidad de fuentes registradas.

![Pantalla de Inicio](/img/inicio.png)

Además, la pantalla cuenta con accesos rápidos a funcionalidades importantes del sistema, como la gestión de cambios pendientes de devolución y egreso de productos.

También permite acceder de forma directa a apartados relacionados con la información del **Ente Regulador Salta** y el **Organigrama Institucional**.

Esta pantalla funciona como un panel principal de consulta, permitiendo al usuario tener una visión general del estado actual del inventario y acceder rápidamente a las secciones más utilizadas.

# Inicio de Existencias

En esta pantalla podés **ver un resumen de los elementos registrados** y elegir qué querés hacer: **registrar productos** o **consultar los que ya están cargados**.

![Pantalla de Inicio de Existencias](/img/relevamiento/inicio-existencias.jpg)

## 1. ¿Qué significan los números de arriba?

Los tres recuadros de la parte superior muestran cantidades de elementos registrados en el sistema:

| Lo que dice la pantalla | Qué significa |
| --- | --- |
| **En depósito** | Cantidad de unidades registradas en depósito. |
| **Pendiente de egreso** | Cantidad de unidades que figuran pendientes de egreso. |
| **Relevado/Egresado** | Cantidad de unidades registradas mediante un relevamiento o un egreso. |

Una **unidad** es un elemento individual. Por ejemplo, si se registran tres sillas, son **tres unidades**.

Los números pueden cambiar a medida que se registran elementos. En la imagen de ejemplo se ven **0**, **0** y **2**. Son valores de esa captura, no cantidades fijas.

## 2. ¿Qué puedo hacer desde esta pantalla?

### Registrar elementos: Relevar productos

Usá esta opción cuando necesites **cargar en el sistema algo que ya se encuentra físicamente** en una oficina o en una fuente de abastecimiento.

**Ejemplo:** encontraste dos escritorios en una oficina y querés dejar registrado que están allí.

1. Buscá el recuadro **Relevar productos**.
2. Presioná el botón **RELEVAR PRODUCTOS**.
3. Seguí las instrucciones de [Cómo relevar productos](./relevar-productos.md).

### Consultar elementos: Detalle de las Existencias

Usá esta opción cuando quieras **saber qué productos están registrados en un lugar**, cuántos hay y cómo es cada uno.

**Ejemplo:** querés saber cuántas sillas aparecen registradas en una oficina.

1. Buscá el recuadro **Detalle de las Existencias**.
2. Presioná **VER DETALLE**.
3. Ingresá a **Relevado/Egresado** y seguí la guía [Cómo consultar las existencias](./detalle-existencias.md).

:::tip Si es la primera vez que usás el sistema
Para **registrar** elementos, elegí **RELEVAR PRODUCTOS**. Para **consultar** elementos que ya están registrados, elegí **VER DETALLE**. Son dos tareas diferentes.
:::

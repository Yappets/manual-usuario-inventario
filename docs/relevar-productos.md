# Cómo relevar productos

**Relevar** significa **registrar en el sistema los elementos que ya están físicamente en un lugar**.

Por ejemplo: si en una oficina hay tres sillas y una mesa, podés registrar esos productos, indicar cómo son y dejar asentado dónde están.

En esta guía vamos a hacerlo paso a paso.

## 1. Abrir la pantalla para registrar productos

1. Entrá a **Inicio de Existencias**.
2. Presioná **RELEVAR PRODUCTOS**.

Se abre una pantalla con dos recuadros:

- **Producto y cantidad:** para indicar qué elemento encontraste, cuántos hay y sus características.
- **Ubicación a relevar:** para indicar dónde se encuentra ese elemento.

![Pantalla inicial para registrar un producto](/img/relevamiento/formulario-inicial.jpg)

:::info Antes de presionar AGREGAR
Es necesario completar **los datos del producto** y **el lugar donde está ubicado**. Podés empezar por cualquiera de los dos recuadros.
:::

## 2. Elegir qué producto vas a registrar

Supongamos que encontraste **una silla**.

1. En **Producto y cantidad**, presioná **SELECCIONAR PRODUCTO**.
2. Se abre una ventana para buscar productos. En **Grupo** aparece **MYA - MOBILIARIO Y ACCESORIOS DE OFICINA**.
3. En **Subgrupo**, elegí el tipo de elemento. Por ejemplo, **SLL - SILLAS**.
4. Buscá el producto correcto en la lista de **Productos encontrados**.
5. Marcá su casilla **Seleccionar**.

![Ventana para buscar el producto](/img/relevamiento/selector-producto.jpg)

![Lista de tipos de productos, llamados subgrupos](/img/relevamiento/selector-subgrupos.jpg)

![Ejemplo de una silla encontrada en la lista](/img/relevamiento/resultado-producto.jpg)

**¿Qué es un subgrupo?** Es una forma de ordenar los productos por tipo. Por ejemplo, **Sillas**, **Mesas**, **Escritorios** o **Aire acondicionado**.

Si la lista es muy larga, podés escribir una palabra en el campo **Producto** y presionar **BUSCAR**. El botón **LIMPIAR** borra lo escrito para empezar otra búsqueda.

En el ejemplo de la imagen, la silla figura con el código **MYA-SLL-SILLA0000001**. El código sirve para distinguir ese producto de otros del catálogo.

## 3. Escribir cuántas unidades encontraste

Cuando regreses al formulario, verás el producto elegido.

1. Buscá el campo **Cantidad**.
2. Escribí cuántos elementos iguales encontraste. Por ejemplo, **1** si es una silla o **3** si son tres sillas.

![Producto elegido y campo para ingresar la cantidad](/img/relevamiento/producto-cantidad.jpg)

:::caution Si cambiás la cantidad más adelante
Si ya habías indicado las características de las unidades y después modificás **Cantidad**, esas características se borran. Tendrás que configurarlas nuevamente para la nueva cantidad.
:::

## 4. Indicar las características del producto

Las **características** sirven para describir cómo es cada elemento: por ejemplo, su **color, material, tipo y estado**.

1. Presioná **CONFIGURAR CARACTERÍSTICAS**.
2. Se abre una ventana con las unidades que escribiste en **Cantidad**.

![Ventana de características antes de completar los datos](/img/relevamiento/caracteristicas-sin-configurar.jpg)

### Paso 4.1. Completar cómo es el elemento

En la ventana, indicá:

- **Estado:** cómo se encuentra el elemento. Por ejemplo, **Bueno**.
- **Origen:** cómo fue adquirido o incorporado por la empresa. Por ejemplo, **Gestión COSAYSA**.
- **Características específicas del subgrupo:** otros datos propios de ese producto. Para una silla pueden ser el material, el tipo, si tiene apoyabrazos, el tapizado y el color.

**Completá todos los campos de características que aparezcan para ese producto.** Los campos pueden ser diferentes según se trate de una silla, un monitor o una mesa.

### Paso 4.2. Elegir a qué unidades se les aplican

1. En **Características por unidad**, marcá la casilla de la unidad que querés describir.
2. Si varias unidades son iguales, podés marcar **más de una**.
3. Presioná **APLICAR CARACTERÍSTICAS**.
4. Revisá que las unidades marcadas aparezcan como configuradas.

![Características completas y unidad seleccionada](/img/relevamiento/caracteristicas-seleccionadas.jpg)

**Ejemplo con tres monitores:** si dos tienen las mismas características y el tercero es diferente, seleccioná primero los dos iguales y presioná **APLICAR CARACTERÍSTICAS**. Después completá los datos del tercero, marcá esa unidad y volvé a presionar **APLICAR CARACTERÍSTICAS**.

Así cada monitor queda registrado con sus propias características, aunque sean del mismo producto.

### Paso 4.3. Revisar y confirmar

- Mirá el resumen que aparece para cada unidad.
- Si una unidad quedó mal configurada, presioná **QUITAR CARACTERÍSTICAS** en esa unidad y cargá los datos correctos.
- Cuando todas las unidades estén bien configuradas, presioná **CONFIRMAR**.

![Resumen de las características aplicadas a las unidades](/img/relevamiento/caracteristicas-aplicadas.jpg)

**Importante:** este botón **CONFIRMAR** guarda las características en el formulario que estás completando. **Todavía no finaliza el relevamiento.**

## 5. Indicar dónde se encuentra el producto

En el recuadro **Ubicación a relevar**, elegí si el elemento está en una **Oficina** o en una **Fuente**.

Una *fuente de abastecimiento* es otro tipo de lugar de la empresa donde también pueden encontrarse productos registrados.

### Opción A. Si el producto está en una oficina

1. Seleccioná **Oficina**.
2. Presioná **SELECCIONAR OFICINA**.
3. Se abrirá una ventana con dos partes. En **1. Elegí un sector** (izquierda), abrí las ramas del organigrama y elegí el sector de la empresa.
4. En **2. Elegí una oficina** (derecha), aparecerán las oficinas que pertenecen a ese sector. Presioná **SELECCIONAR** en la oficina correcta.
5. Revisá **Selección actual** para comprobar el nombre de la oficina y su sector.
6. Presioná **CONFIRMAR**.

![Selección de un sector y una oficina](/img/relevamiento/seleccion-oficina.jpg)

**¿Qué es el organigrama?** Es la forma en que se muestran las áreas o sectores de la empresa. Para encontrar una oficina, primero elegís su **sector** y después su **nombre**.

Si una oficina no aparece, puede ser porque todavía no está registrada para ese sector o porque no tenés acceso a ella. Podés consultar [Cómo incorporar oficinas](./importar-oficinas.md).

### Opción B. Si el producto está en una fuente de abastecimiento

1. Seleccioná **Fuente**.
2. Abrí la opción para **seleccionar la fuente de abastecimiento**.
3. Se abre una ventana con un mapa y una lista de fuentes.
4. Buscá la fuente por su nombre o, si hace falta, utilizá las opciones **Localidad**, **Tipo de Fuente** y **Fuente** para reducir la lista.
5. Seleccioná la fuente correcta en el listado y presioná **GUARDAR**.

![Mapa del selector de fuentes de abastecimiento](/img/relevamiento/selector-fuente-mapa.jpg)

![Listado donde se selecciona la fuente correcta](/img/relevamiento/selector-fuente-listado.jpg)

El mapa puede ayudarte a orientarte, pero **lo más importante es comprobar el nombre** de la fuente. Algunas pueden figurar sin coordenadas de ubicación correctas.

:::note Si cambiás de Oficina a Fuente, o al revés
El sistema borra la selección anterior del otro tipo de lugar. Revisá que hayas dejado elegida la ubicación correcta.
:::

## 6. Agregar el producto a la lista

Cuando ya completaste **producto**, **cantidad**, **características** (si corresponden) y **ubicación**, presioná **AGREGAR**.

El elemento aparecerá en una tabla de la parte inferior. Esa tabla es **una lista para revisar antes de guardar definitivamente**.

![Lista de productos agregados para revisar](/img/relevamiento/tabla-relevamiento.jpg)

En la lista podés ver:

| Columna | Qué te muestra |
| --- | --- |
| **Código** | Código del producto elegido. |
| **Descripción** | Nombre del producto. |
| **Ubicación** | Oficina y sector, o fuente elegida. |
| **Cantidad** | Cuántas unidades cargaste. |
| **Características** | Resumen de los datos de las unidades. |
| **Acciones** | Botones **VER DETALLE** y **QUITAR**. |

Después de presionar **AGREGAR**, el recuadro **Producto y cantidad** queda vacío para cargar otro producto, pero **la ubicación se mantiene**. Si agregás otros elementos, verificá que estén en ese mismo lugar o cambiá la ubicación antes de continuar.

Si encontraste **tres sillas iguales en la misma oficina**, poné **Cantidad: 3**. No intentes agregar tres veces el mismo producto en esa ubicación, porque el sistema no permite repetir esa combinación dentro del mismo relevamiento.

## 7. Revisar o quitar algo de la lista

Antes de finalizar, revisá cada fila de la tabla:

- **VER DETALLE:** muestra cómo quedó registrada **cada unidad** y sus características.
- **QUITAR:** saca de la lista **todo ese producto**. Si te equivocaste, tendrás que cargar nuevamente el producto, su cantidad y sus características. **No hay un botón para editar esa fila.**

![Detalle de las características de cada unidad](/img/relevamiento/detalle-caracteristicas.jpg)

**Atención:** **QUITAR CARACTERÍSTICAS**, dentro de la ventana de configuración, no es lo mismo que **QUITAR**, en la lista final. El primero borra las características de una unidad; el segundo quita el producto completo de la lista.

## 8. Guardar el relevamiento

Revisá que la lista tenga los productos correctos y que coincidan **cantidades, ubicaciones y características**.

1. Comprobá los datos de los productos agregados.
2. Presioná **CONFIRMAR RELEVAMIENTO**.
3. Revisá el mensaje que muestre el sistema.

**Recién en este paso se confirma el relevamiento.** Presionar **AGREGAR** solamente prepara el producto en la lista.

### Ejemplo: registrar una silla

1. Elegís el producto **SILLA** del subgrupo **SLL - SILLAS**.
2. Escribís **Cantidad: 1**.
3. En **CONFIGURAR CARACTERÍSTICAS**, indicás los datos correspondientes. Por ejemplo: estado **Bueno**, origen **Gestión COSAYSA**, material **Metal**, tipo **Giratoria**, apoyabrazos **Sí**, tapizado **Tela** y color **Negro**.
4. Seleccionás la oficina **Desarrollo 1** del sector **Desarrollo.**.
5. Presionás **AGREGAR** y revisás la fila.
6. Presionás **CONFIRMAR RELEVAMIENTO**.

## ¿Qué hago si aparece un problema?

| Si ocurre esto… | Qué podés hacer |
| --- | --- |
| No elegiste un producto | Volvé a **SELECCIONAR PRODUCTO** y elegí uno. |
| La cantidad está vacía o es cero | Escribí una cantidad **mayor que cero**. |
| Faltan características | Abrí **CONFIGURAR CARACTERÍSTICAS**, completá los datos y aplicalos a las unidades que correspondan. |
| No elegiste una oficina | Seleccioná primero el **sector** y después la **oficina**. |
| No elegiste una fuente | Abrí el selector y seleccioná una fuente válida. |
| El producto ya está cargado para esa ubicación | Revisá la lista. Si necesitás más unidades del mismo producto, usá **Cantidad** al cargarlo. |
| Agregaste el producto equivocado | Presioná **QUITAR** en la lista y cargalo otra vez. |
| No hay productos en la lista | Agregá al menos uno antes de confirmar el relevamiento. |

:::tip Para recordar
**SELECCIONAR PRODUCTO → CANTIDAD → CONFIGURAR CARACTERÍSTICAS → UBICACIÓN → AGREGAR → CONFIRMAR RELEVAMIENTO.**
:::
